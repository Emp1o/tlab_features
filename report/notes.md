## Что в данных (по описанию на странице)
- Данные с реального интернет-магазина, все значения захешированы
- Период: 4,5 месяца (точные даты на странице не указаны)
- events.csv — события поведения: timestamp (Unix, мс), visitorid, event, itemid, transactionid
  - типы событий: view, addtocart, transaction
  - всего 2 756 101 событие: 2 664 312 просмотров, 69 332 добавления в корзину, 22 457 покупок
  - 1 407 580 уникальных посетителей
- item_properties_part1.csv, item_properties_part2.csv — свойства товаров (один файл, разделён на две части из-за размера)
  - 20 275 902 строки, 417 053 уникальных товара
  - столбцы: timestamp, itemid, property, value
  - свойства меняются во времени; хранится журнал изменений: значение записано, только когда оно поменялось
  - не захешированы только categoryid (категория) и available (1 — товар в наличии)
  - свойства есть примерно для 90% событий
- category_tree.csv — дерево категорий «потомок — родитель», 1669 строк
